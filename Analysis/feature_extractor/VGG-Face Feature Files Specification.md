# VGG-Face Feature Files Specification

本目录包含基于 **VGG-Face** 网络提取的人脸特征文件（`.pt`），用于后续的表情分析、时序建模与特征空间研究。

所有特征均由 **224×224 预处理后的人脸图像**提取，并且**严格按文件名排序**，保证时间顺序一致。

---

## 1. `vggface_fc7_*.pt`

### 来源

* 网络：**VGG-Face（conv + fc6 + fc7）**
* 提取层：`fc7`
* 维度：4096

### 文件结构

```python
data = torch.load("vggface_fc7_xxx.pt")

data.keys()
# dict_keys(['names', 'feats'])
```

#### `data["names"]`

* 类型：`List[str]`
* 长度：`T`
* 含义：
  每一帧对应的原始图像文件名（按排序后的顺序）

#### `data["feats"]`

* 类型：`torch.Tensor`
* 形状：

```text
[T, 4096]
```

* 含义：
  每一行是对应图像的 **fc7 embedding 向量**

### 特征语义

* `fc7` 是 VGG-Face 的倒数第二层
* 受到身份分类任务的强监督
* 具有较强的语义抽象能力
* 对姿态、光照、局部噪声相对鲁棒

### 推荐用途

* 表情/笑容的**整体语义轨迹**
* 相似度计算（cosine / L2）
* PCA / UMAP / 聚类
* 时序模型（LSTM / TCN / Transformer）的高层输入

---

## 2. `*_conv5_3.pt`

### 来源

* 网络：**VGGFace_conv**
* 提取位置：`maxp_5_3` 之后
* 原始空间特征图

### 文件结构

```python
data = torch.load("xxx_conv5_3.pt")

data.keys()
# dict_keys(['names', 'conv5_3'])
```

#### `data["names"]`

* 类型：`List[str]`
* 长度：`T`
* 含义：
  每一帧对应的原始图像文件名（与 fc7 / gap512 一一对应）

#### `data["conv5_3"]`

* 类型：`torch.Tensor`
* 形状：

```text
[T, 512, 7, 7]
```

### 特征语义

* 每一帧是一个 **512 通道 × 7×7 空间特征图**
* 保留明显的空间结构信息
* 对局部表情变化（嘴角、眼部、AU）更敏感
* 信息量最大，但噪声也相对更高

### 推荐用途

* 细粒度表情变化分析
* 空间注意力 / 局部响应分析
* 自定义 pooling / PCA / 1×1 conv 降维
* 高阶时序建模（在降维后使用）

⚠️ 注意：

* 存储与计算成本较高
* 不建议直接用于简单相似度计算

---

## 3. `*_gap512.pt`（Conv5_3 + GAP）

### 来源

* 基于 `conv5_3`
* 对空间维度 `(7×7)` 做 **Global Average Pooling (GAP)**

### 文件结构

```python
data = torch.load("xxx_gap512.pt")

data.keys()
# dict_keys(['names', 'gap512'])
```

#### `data["names"]`

* 类型：`List[str]`
* 长度：`T`

#### `data["gap512"]`

* 类型：`torch.Tensor`
* 形状：

```text
[T, 512]
```

### 特征语义

* 每一维对应一个卷积通道的**全局响应强度**
* 相比 `conv5_3`：

  * 空间信息被压缩
  * 噪声更小
  * 表征更稳定
* 相比 `fc7`：

  * 语义约束更弱
  * 保留更多“表情相关”的中层信息

### 推荐用途

* 表情时序建模（轻量级）
* 动态变化分析（Δfeature）
* fc7 与 conv5_3 之间的折中方案
* 作为下游模型（MLP / TCN）的输入

---

## 4. 三种特征的对比总结

| 特征      | 形状            | 空间信息  | 语义抽象  | 计算成本 | 典型用途     |
| ------- | ------------- | ----- | ----- | ---- | -------- |
| fc7     | `[T,4096]`    | ✗     | ★★★★☆ | 低    | 相似度 / 轨迹 |
| conv5_3 | `[T,512,7,7]` | ✓✓✓   | ★★☆☆☆ | 高    | 局部分析     |
| gap512  | `[T,512]`     | ✓（隐式） | ★★★☆☆ | 中    | 时序建模     |

---

## 5. 对齐关系（重要）

* 三种 `.pt` 文件中：

  * `names[i]`
  * `feats[i]` / `conv5_3[i]` / `gap512[i]`
* **始终对应同一张图像**
* 可以安全地在不同特征之间进行逐帧对齐、对比或融合
