s-d plot 计算方法说明

项目：Single_frame_smile | 更新时间：2026-06-02 | 说明对象：smile trajectory 的 projection length、off-axis distance 与 nearest-baseline curve 坐标

1. 目的

s-d plot 用来把一条高维笑容轨迹压缩成二维关系图： 横轴 s 表示沿某一条基准笑容轴的推进量，纵轴 d 表示偏离这条基准轴的距离。

当前主要使用两条基准轴：

  • truesmile axis：用真笑代表轨迹的首尾连线定义。
  • polite axis：用礼貌笑代表轨迹的首尾连线定义。

3. 基准轴定义

对某个基准类别 a，先取它的代表轨迹： 

P_a(t), t = 0, 1, ..., 19

基准轴使用该代表轨迹的首尾连线： 

g = P_a(19) - P_a(0)
axis_norm = ||g||
u = g / ||g||

其中 u 是单位方向向量。若 axis_norm 太小，说明首尾几乎没有运动，无法稳定定义投影轴。

4. s 和 d 的正式计算

对任意类别或任意单条样本轨迹 X(t)，当前计算不是直接使用全局坐标，而是先转成相对于自身起点的动态位移： 

delta(t) = X(t) - X(0)

然后计算沿基准轴的投影长度： 

s(t) = <delta(t), u>

投影向量为： 

projection_vector(t) = s(t) * u

偏离基准轴的残差向量为： 

residual(t) = delta(t) - projection_vector(t)

off-axis distance 为： 

d(t) = ||residual(t)||

如果需要归一化比例，则使用： 

s_ratio(t) = s(t) / axis_norm
d_ratio(t) = d(t) / axis_norm
关键点：s-d plot 中的曲线描述的是“每条轨迹从自身起点出发后如何运动”，不是“不同类别在同一个绝对空间原点附近的位置分布”。

5. Prototype 与样本级计算

5.1 Prototype 曲线

对每个类别的代表轨迹计算一条 s-d 曲线。当前有三类： polite、truesmile、ambiguous。

  • methodA：median trajectory，在每个时间点和每个维度上取类别内中位数。
  • methodB：medoid trajectory，从真实样本中选出到同类其他样本总距离最小的一条。
  • DTW representative：用类内 DTW 总距离最小的真实序列作为代表。

5.2 样本级曲线

除了 prototype，也会对每一条样本序列计算同样的 s(t) 与 d(t)。 这一步用于生成 all-sequence s-d plot 和统计表。

当前 all-sequence 图显示类别之间混合较明显，因此它更适合用来检查 prototype 结论是否过度概括，而不是单独作为类别分离证据。

7. 当前结果的解释原则

  1. s 大表示该轨迹沿基准笑容轴推进得更多。
  2. d 大表示该轨迹虽然在变化，但变化方向更多偏离基准轴。
  3. 以 truesmile 为轴时，truesmile 终点的 d 必然为 0，因为轴本身由它的首尾点定义。
  4. 中间时间点的 truesmile d(t) 可以不为 0，这说明真笑轨迹本身不是一条直线。
  5. prototype 层面的方向差异明显，但 all-sequence s-d 图存在较强混合，不能过度解释为完整类别分布已经分离。
  6. nearest6 图只表示代表序列附近的局部情况，不代表完整类别分布。

9. Nearest-baseline curve 新坐标定义

2026-06-02 更新：老板提出的新方法中，新的二维坐标不是“nearest point 自己在旧 fixed-axis s-d plot 中的 (s,d)”。正确理解是： 

x 轴 = nearest point 在 baseline curve 上的 progress
y 轴 = C2 当前点到 nearest point 的连线长度

9.1 曲线与基准轴

假设有两条高维轨迹： 

C_baseline(t)
C_2(t)

其中 C_baseline 不改变。主轴仍然按之前 fixed-axis s-d plot 的方式定义： 

g = C_baseline(100%) - C_baseline(0%)
u = g / ||g||

9.2 对 C2 每个阶段寻找 baseline 上的最近点

对于 C_2 上某个阶段 t 的点： 

x_t = C_2(t)

在整条 C_baseline 上找最近点： 

tau*(t) = argmin_tau || C_2(t) - C_baseline(tau) ||

最近点为： 

y_t = C_baseline(tau*(t))

9.3 nearest vector 与新的 y 轴

将 C_2(t) 和最近点 C_baseline(tau*(t)) 连接，得到 nearest vector： 

n(t) = C_2(t) - C_baseline(tau*(t))

新图的 y 轴是这个 nearest vector 的长度： 

d_new(t) = || n(t) ||
         = || C_2(t) - C_baseline(tau*(t)) ||

9.4 nearest progress 与新的 x 轴

新图的 x 轴是最近点在 C_baseline 上的 progress。若用曲线参数本身表示 progress： 

s_new(t) = tau*(t)

如果图中希望显示为百分比，则使用： 

s_new_percent(t) = 100 * tau*(t)

如果后续实现中希望与旧 fixed-axis 的 normalized along-axis progress 对齐，也可以补充报告： 

s_axis(t) =
  < C_baseline(tau*(t)) - C_baseline(0%), u > / ||g||

但本方法的核心坐标定义仍然是 nearest baseline progress 和 nearest vector length。

9.5 新曲线

对 C_2 的每个阶段 t，新图中的点是： 

(s_new(t), d_new(t))

连接所有阶段的这些点，得到新的 nearest-baseline s-d curve： 

{ (s_new(t), d_new(t)) | t = 5%, 10%, 15%, ..., 100% }
重要更正：这里的 d_new(t) 不是最近点在旧 s-d plot 中的 off-axis distance。 它是 C_2(t) 到 baseline curve 最近点的高维欧氏距离。

9.6 这个图可以看什么

  • 它显示 C_2 每个阶段最接近 C_baseline 的哪个 progress。
  • 如果 s_new 长期停留在 baseline 的早期阶段，说明 C_2 即使发展到后期，也更像 baseline 的早期状态。
  • 如果 s_new 随着 C_2 的阶段从 0% 到 100% 单调推进，说明两条曲线存在比较稳定的阶段对应关系。
  • 如果 d_new 长期较大，说明即使找到最近点，C_2 仍然离 baseline trajectory 较远。
  • 如果 s_new 跳来跳去，说明 C_2 和 baseline 的时序对应关系不稳定。
