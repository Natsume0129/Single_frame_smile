# analysis_sequence Coding Explanation (English)

## 1. Design Principles
- The pipeline is split into small scripts: one script per sub-task.
- Shared logic is implemented in a base class, then reused by all step scripts.
- Default input root: `E:\Matsuda_data\2-18meeting`
- Default output root: `E:\Matsuda_data\2-27meeting`

---

## 2. Base Class and Shared Utilities

### `common/base.py`
This module provides:
- `PipelineConfig`: unified runtime config (input/output root, weights, fps, normalized length, device, etc.).
- `SequenceTaskBase`: common capabilities for all step scripts:
  - Auto-creates output folders: `prototypes/`, `metrics/`, `plots/`, `csv/`, `report/`
  - Unified sequence discovery: scans only `polite/truesmile/ambiguous`, ignores `videos/video`
  - Unified frame sorting: extracts the last integer from filename and sorts numerically
  - Unified I/O helpers for `npy/json/csv`
  - Unified per-sequence output path helpers

---

## 3. Step-by-Step Scripts

### `01_extract_features.py`
- Purpose: extract VGG-Face `fc7` (4096-dim) features for each sequence.
- Reuses model and preprocess from `Analysis/feature_extractor/feature_extractor_fc7.py`.
- Outputs:
  - `metrics/sequence_features/<class>/<seq>/sequence_features.npy` (`[T, D]`)
  - `metrics/sequence_features/<class>/<seq>/frame_names.json`

### `02_baseline_align.py`
- Purpose: baseline alignment with `f0 = mean(f[0:5])`, then `f_rel = f - f0`.
- Outputs:
  - `metrics/sequence_features_rel/<class>/<seq>/sequence_features_rel.npy`
  - `metrics/sequence_features_rel/<class>/<seq>/baseline_f0.npy`

### `03_compute_magnitude.py`
- Purpose: compute `d(t)=||f_rel(t)||` and magnitude metrics.
- Outputs:
  - `metrics/distance/<class>/<seq>/distance_curve.npy`
  - `metrics/distance/<class>/<seq>/metrics.json`

### `04_compute_velocity.py`
- Purpose: compute `v(0)=0, v(t)=||f_rel(t)-f_rel(t-1)||` and velocity metrics.
- Outputs:
  - `metrics/velocity/<class>/<seq>/velocity_curve.npy`
  - `metrics/velocity/<class>/<seq>/metrics.json`

### `05_compute_duration_stats.py`
- Purpose: compute duration as `duration_sec = frames / fps` (not onset).
- Outputs:
  - `csv/duration_stats.csv` (class-level average duration)
  - `csv/duration_per_sequence.csv` (per-sequence duration details)

### `06_time_normalize.py`
- Purpose: linearly resample each sequence to fixed length `N=20`; copy sampled frames.
- Outputs:
  - `metrics/normalized/<class>/<seq>/normalized_sequence.npy` (`[20,D]`)
  - `metrics/normalized/<class>/<seq>/distance_norm.npy` (`[20]`)
  - `metrics/normalized/<class>/<seq>/velocity_norm.npy` (`[20]`)
  - `metrics/normalized/<class>/<seq>/sampled_frames.json`
  - `metrics/normalized_frames/<class>/<seq>/000.png ... 019.png`

### `07_build_prototypes.py`
- Purpose:
  - Required: class-wise median prototype (element-wise median over sequences)
  - Optional supplement: medoid prototype with Frobenius distance
- Outputs:
  - `prototypes/prototype_polite.npy`
  - `prototypes/prototype_truesmile.npy`
  - `prototypes/prototype_ambiguous.npy`
  - `prototypes/prototype_<class>_medoid.npy`
  - `prototypes/prototype_meta.json`

### `08_class_difference_vectors.py`
- Purpose: compute 3 class-pair difference trajectories (`[20,D]`).
- Output:
  - `prototypes/class_difference_vectors.npy` (dict with 3 keys):
    - `polite_vs_truesmile`
    - `polite_vs_ambiguous`
    - `truesmile_vs_ambiguous`

### `09_segment_vectors.py`
- Purpose: compute segment vectors `f(t+1)-f(t)` for class prototypes only.
- Output:
  - `prototypes/segment_vectors.npy` (dict keyed by class name)

### `10_projection_pca.py`
- Purpose: project trajectories to 2D with a two-stage PCA pipeline, using time-point projection + connected lines.
- Method:
  - `StandardScaler`
  - PCA stage 1: `4096 -> mid_dim` (default `50`, configurable by `--pca_mid_dim`)
  - PCA stage 2: `mid_dim -> 2` for plotting
- Outputs:
  - `plots/trajectory_plot.png`
  - `plots/trajectory_plot_polite.png`
  - `plots/trajectory_plot_ambiguous.png`
  - `plots/trajectory_plot_truesmile.png`
  - `plots/trajectory_plot_cross.png`
  - `prototypes/pca_model_2d.npz` (scaler + two-stage PCA parameters)

### `11_class_distance_curve.py`
- Purpose: compute `||A(t)-B(t)||` for each prototype pair over time, with peak marker.
- Output:
  - `csv/class_distance_curve.csv`

### `12_projection_scores.py`
- Purpose: for each sample/time/pair, compute projection score `dot(f_norm(t), Δ_pair(t))`.
- Output:
  - `csv/projection_scores.csv`

### `13_generate_visualizations.py`
- Purpose: generate required summary plots.
- Outputs:
  - `plots/mean_magnitude_curve.png`
  - `plots/mean_velocity_curve.png`
  - `plots/class_distance_over_time.png`
  - `plots/duration_distribution.png`
  - (trajectory plots are generated by `10_projection_pca.py`)
  - `csv/mean_magnitude_curve.csv`
  - `csv/mean_velocity_curve.csv`

### `14_generate_dataset_report.py`
- Purpose: generate final dataset report.
- Output:
  - `csv/dataset_report.csv`
  - Fields: `class, sequence_id, frames, duration_sec, peak_magnitude, mean_velocity`

## 4. Sequential Execution

### `run_pipeline.ps1`
- Purpose: run step scripts from `01` to `14` in order.
- Usage (inside `analysis_sequence`):

```powershell
powershell -ExecutionPolicy Bypass -File .\run_pipeline.ps1
```
