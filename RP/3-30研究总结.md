# 3-30研究总结

## 1. 研究主线概述

到目前为止，我们围绕“笑容在高维特征空间中的动态轨迹差异”做了三大块工作：

1. `analysis_projection`
   - 以时序轨迹为中心的 prototype、主轴、距离与偏离分析
2. `DTW`
   - 以动态模式相似性为中心的 DTW 类内 / 类间分析
3. `analysis_minimum`
   - 以时间对齐后的同步最小距离为中心的补充分析

研究对象始终是三类笑容：

- `polite`
- `truesmile`
- `ambiguous`

基础数据流程是：

1. 提取每帧的 VGG-Face fc7 特征
2. 用前 5 帧均值做 baseline 对齐，得到 `f_rel(t)`
3. 视具体分析需要，使用：
   - 原始长度序列
   - 或重采样后的 20 点序列

### 2.4 synchronized minimum distance 新定义分析

根据和教授的讨论，我们把 minimum distance 的定义进一步收紧为：

```text
min_t ||C1(t) - C2(t)||
```

也就是：

- 只看已经时间对齐后的同一个时间点上的最小距离
- 不再允许 `t1 != t2`

## 3. 到目前为止比较稳定的结果

### 3.1 在 projection 分析里

比较稳定的结论有：

1. `polite` 和 `ambiguous` 整体上更接近彼此
2. 它们与 `truesmile` 的差异更明显
3. 随着笑容展开，类别间距离一般会增大
4. `polite` 和 `ambiguous` 没有显著沿 true-smile 主轴推进
5. 它们更像是往特征空间中的其他方向发展

### 3.2 在 polite 轴分析里

以 polite smile 为主轴后：

1. polite 自身相对 polite 主轴偏离更小
2. true smile 相对 polite 主轴偏离更大

这说明：

- polite smile 可能也有自己的动态方向
- polite 不能只理解为“偏离 true smile”

### 3.3 在 DTW 分析里

跨多个 branch 都比较一致的结论是：

1. `ambiguous_vs_polite` 通常是最接近的类间 pair
2. `polite_vs_polite` 往往是最紧的类内 pair
3. `truesmile` 与另外两类的距离通常更大

所以从动态模式上看：

- `ambiguous` 更接近 `polite`
- `truesmile` 与另外两类分得更开

### 3.4 在 minimum distance 分析里

旧版 cross-time minimum distance 和新版 synchronized minimum distance 都提示：

1. 最小距离经常出现在 very early stage
2. 这很可能同时受到：
   - 数据本身的 neutral 相似性
   - baseline alignment
   - time normalization / resampling
   的共同影响

在去掉前 5 帧、前 10 帧后：

1. minimum distance 整体变大
2. 但类别关系仍然基本保持：
   - `ambiguous` 和 `polite` 最近
   - `truesmile` 与另外两类更远

## 4. 已经明确不继续推进或暂时搁置的方向

### 4.1 法平面 / 法超平面相关距离

这个方向后来和教授讨论过，结论很明确：

- 现阶段先不做
- 可以直接视为搁置

主要原因是：

1. 高维空间里法超平面的解释价值不明确
2. 即使能算出距离，也不清楚它回答了什么研究问题
3. 教授已经明确表示 “forget it”

所以这条线目前不进入正式主流程。

### 4.2 旧版 cross-time minimum distance 的定位

旧版：

```text
min_{t1,t2} ||C1(t1) - C2(t2)||
```

现在更多作为：

- exploratory analysis
- 或用于理解“局部最近接近”

但它不是教授现在真正想要的 minimum distance 定义。

现在更正式的 minimum 定义是：

```text
min_t ||C1(t) - C2(t)||
```

## 5. 当前阶段的问题和局限

### 5.1 单一主轴模型过于粗糙

无论 true-smile 轴还是 polite-smile 轴，本质上都只是首尾连线。

问题在于：

- 真正的 smile trajectory 很可能是弯曲的
- 所以单一主轴只能提供粗粒度参考

### 5.2 prototype 与样本均值不一定一致

在 band plot 中我们已经看到：

- prototype 曲线不一定落在样本均值和中间区间中间

这是因为：

- prototype 是在 feature space 里构造的
- 样本均值是在 metric space 里统计的

这两者不能简单等价。

### 5.3 minimum distance 很容易被 early stage 主导

这一点在几种 minimum distance 分析里都很明显。

所以如果继续做 minimum 相关分析，需要非常明确：

- 是看全局 minimum
- 还是看去掉前段后的 minimum
- 还是只看中后段

### 5.4 DTW 数值跨分支不可直接比较

尤其是：

- 1 维 magnitude / velocity DTW
- 与 PCA 10/20/30 维 DTW

它们的尺度不同，所以：

- 只能在 branch 内部比较
- 更应该看排序和结构，而不是绝对值大小

## 6. 到 3/30 的阶段性结论

到目前为止，我认为比较稳的阶段性结论是：

1. 不同 smile 类别确实对应不同的动态轨迹
2. `polite` 与 `ambiguous` 更接近彼此
3. `truesmile` 和另外两类之间存在更明显的差异
4. polite 与 ambiguous 并不是简单沿 true-smile 方向展开
5. polite 也可能具有自己的动态方向
6. minimum distance 的结果需要谨慎解释，因为它非常容易受序列起始阶段和预处理定义影响
